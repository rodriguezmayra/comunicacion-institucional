

# Sistema de Comunicación Institucional

Es un sistema de comunicación diseñado para la Escuela Técnica "Dionisio Díaz" de Treinta y Tres como parte del proyecto final del bachillerato en Tecnologías de la Información.



## Funcionalidades principales

- Notificaciones: Difusión de avisos y comunicados institucionales publicados por personal autorizado.
- Horarios: Consulta de los horarios del grupo por parte de los estudiantes.
- Calendario: Visualización de eventos y actividades programadas en el mes.

Nota
Actualmente, el inicio de sesión se da en base a tres roles: Estudiante, Docente y Administrativo.
El acceso a algunas funcionalidades está limitado a ciertos tipos de usuario.


## Tecnologías

**Cliente:** HTML5, CSS3, JavaScript

**Servidor:** Apache, PHP

**Base de datos:** MariaDB

**Control de versiones:** Git y Github
